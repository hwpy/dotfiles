# AGENTS.md

## Deployment

This repo uses **GNU Stow**. Each top-level directory is a package that mirrors `$HOME`:

```
stow <package>   # deploy one tool's config
```

Example: `nvim/.config/nvim/init.lua` → `~/.config/nvim/init.lua` after `stow nvim`.

## Commit messages

`type(scope): описание на русском`

Types: `feat`, `fix`, `refactor`, `perf`. Scope matches the top-level directory name (e.g. `nvim`, `tmux`, `sxhkd`).

## Gitignore

`.gitignore` is **whitelist-based** — it ignores everything by default, then explicitly un-ignores each directory. If you add a new top-level directory, append `!/newdir/` to `.gitignore`.

Files intentionally excluded from the repo (gitignored):
- `nvim/.config/nvim/lazy-lock.json` — auto-generated by lazy.nvim, regenerated on `:Lazy sync`
- `alacritty/.config/alacritty/alacritty-local.toml` — local machine-specific overrides
- `touchegg/.config/touchegg/*` (except `touchegg.conf`) — auto-generated

## OS-specific configs

- `zsh_linux/` — Zsh config for Arch Linux
- `zsh_mac/` — Zsh config for macOS

## nvim

- Entry point: `nvim/.config/nvim/init.lua`
- Plugin manager: **lazy.nvim** with defaults `lazy = true`
- Framework: **NvChad v2.5** (imported as a lazy plugin)
- Plugin specs: `nvim/.config/nvim/lua/plugins/*.lua` (auto-imported)
- Config modules: `nvim/.config/nvim/lua/configs/*.lua`
- Snippets: `nvim/.config/nvim/snippets/`
- LSP servers: `pyright`, `ruff`, `gopls`, `lua_ls`, `html`, `cssls`
- Formatter: `conform.nvim` (stylua for Lua only)
- DAP: Python (`debugpy`) and Go (`delve`), managed via Mason
- AI agent config for `gp.nvim` is commented out (in `lua/plugins/gp.lua`)
- Do not touch commented-out code — user may want to restore it
